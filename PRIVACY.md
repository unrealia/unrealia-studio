# Privacy Policy for Unrealia Studio

**Last Updated: October 2026**

## 1. Overview
Unrealia Studio Scheduler is an internal software tool developed and operated solely by Unrealia Studio to manage, organize, and schedule our own original digital content on Pinterest.

## 2. Data Collection and Usage
This application only accesses our own authenticated Pinterest Business account data (specifically boards and pins) via the official Pinterest API v5. We do not collect, store, process, or share any personal data from third-party users or the general public.

## 3. Data Storage and Security
All API tokens and credentials are stored securely on our private local server and are never shared with external parties.

## 4. Contact Information
If you have any questions regarding this Privacy Policy, please contact Unrealia Studio via our official GitHub repository.
